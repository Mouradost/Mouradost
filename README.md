# Hi, I'm Mourad Lablack 👋

**Machine Learning | Spatio-Temporal Modeling | Traffic Forecasting | Rust**

I'm interested in developing machine learning models for complex spatio-temporal systems, with a particular focus on **traffic flow forecasting**. I enjoy exploring deep learning architectures, understanding the mathematical foundations behind them, and writing reliable, efficient software.

I'm also interested in probabilistic generative models, including diffusion models, and idiomatic Rust programming.

### 🔬 Current Focus

- 🚦 **Research:** Traffic flow forecasting and spatio-temporal neural networks.
- 🧠 **Machine Learning:** Exploring deep learning with PyTorch and TensorFlow.
- 🦀 **Systems Programming:** Learning idiomatic Rust and building robust software.
- 🤝 **Collaboration:** Open to interesting projects in machine learning, scientific computing, and open-source software.
